# Instructions et Règles Permanentes de Travail — Sandrine Couture

## 🚨 RÈGLE D'OR D'INTERACTION (À APPLIQUER À CHAQUE PROMPT SANS EXCEPTION)

Avant de modifier, créer ou exécuter le moindre code dans ce projet :

1. **Expliciter ce qui a été compris** : Reformuler avec précision le besoin exprimé par l'utilisateur pour valider l'alignement parfait.
2. **Proposer le plan d'action détaillé** : Présenter la méthode, les fichiers concernés, les choix techniques ou le tableau de recensement.
3. **ATTENDRE LA VALIDATION EXPLICITE DE L'UTILISATEUR** : Ne jamais coder à l'avance. L'agent doit toujours s'arrêter et attendre un feu vert clair ("vas-y", "validé", "ok") avant d'exécuter la moindre modification dans le code source.
